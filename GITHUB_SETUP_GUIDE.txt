PART 3: ENABLE GITHUB PAGES (MAKE IT LIVE!) (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Go to Repository Settings
──────────────────────────────────
1. Click "Settings" tab (top right of repo)
2. Left sidebar → Click "Pages"

STEP 2: Configure GitHub Pages
────────────────────────────────
Under "Build and deployment" section:

1. **Source:** Select "Deploy from a branch"
2. **Branch:** Select "main" 
3. **Folder:** Select "/ (root)"
4. Click "Save" button (blue)

STEP 3: Wait for Deployment
─────────────────────────────
⏳ Wait 2-3 minutes for GitHub to build and deploy

You'll see a green checkmark when it's done ✅

PART 6: TROUBLESHOOTING (IF SOMETHING DOESN'T WORK)
═══════════════════════════════════════════════════════════════════════════════

❌ Logo not showing?
────────────────────
→ Make sure "logo.png" is uploaded to root folder
→ Check filename spelling exactly: logo.png
→ Refresh page (Ctrl+F5 or Cmd+Shift+R)

❌ Videos not playing?
──────────────────────
→ Make sure all .mp4 files are uploaded
→ Check video filenames are EXACTLY as listed:
   - AI Products Video.mp4
   - BeautyCosmetics Velora Satin Glow Lipstick.mp4
   - etc.
→ Wait 5 minutes after upload (GitHub may still be processing)
→ Refresh page in browser

❌ Thumbnails not showing?
──────────────────────────
→ Make sure all *_thumb.jpg files are uploaded
→ Must be in same folder as index.html
→ Filenames must match EXACTLY

❌ Website not showing at all?
──────────────────────────────
→ Go back to Settings → Pages
→ Make sure Source is set to "Deploy from a branch"
→ Make sure Branch is "main" and folder is "/ (root)"
→ Wait 3 minutes and refresh
→ If still not working, click "Re-run job" under deployment

❌ Filter buttons not working?
──────────────────────────────
→ This is a JavaScript feature - refresh page
→ Try different browser (Chrome, Firefox, Safari)
→ Clear browser cache (Ctrl+Shift+Delete)
